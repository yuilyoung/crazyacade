# 캐주얼 음악과 효과음

배경음악과 효과음은 브라우저 Web Audio로 직접 합성한다. 외부 음원 다운로드나 원작 오디오 파일을 사용하지 않는다. 이 프로젝트의 8마디 멜로디·코드 진행·악기 편성은 `Server/public/audio.js`에 정의한다.

| 장면 | 템포 | 편성 |
| --- | ---: | --- |
| 대기 | 112 BPM | 통통 튀는 멜로디, 짧은 코드, 베이스, 가벼운 드럼 |
| 대전 | 136 BPM | 높은 옥타브 장식과 촘촘한 하이햇을 더해 속도감 강조 |
| 결과 | 104 BPM | 긴 코드와 약한 타악기로 마무리 |

효과음은 작은 발걸음, 물방울 설치, 물 터짐, 아이템 상승음, 구조 아르페지오, 승리·패배·무승부 신호를 구분한다. 음색은 사인/삼각파와 자체 생성한 노이즈를 사용한다. 같은 사건의 반복 음량을 제한하고 끝난 음원 노드를 해제한다.

음악과 효과음은 각각 기본 꺼짐이다. 사용자가 켠 뒤에만 오디오 컨텍스트를 만들며 독립 음량을 제공한다. 새로고침이나 뒤로 가기 복원 시 자동으로 소리를 켜지 않는다. 탭 숨김·브라우저 오디오 중단 때 재생과 예약을 멈추고, 복귀 시 이전에 켰던 음악만 재개한다. 오디오 미지원/차단 상태에서도 게임과 시각 안내는 동작한다.

화면 설정의 **풍성하게**는 기존 bright 프로필, **편안하게/최소**는 soft 프로필을 사용한다. Soft는 효과음과 음악의 고주파를 줄이고, 빠른 소리 시작을 완만하게 하며, 효과음/음악 출력에 각각0.6/0.8 배율을 적용한다. 각 채널의 개인 음량은 유지한다. 프로필 변경만으로 음소거를 풀거나 오디오를 시작하지 않는다.

`python3 scripts/audio-smoke.py`는 실제 Chromium에서 재생 제어를 검사하고, 8마디 대전 음악에 주요 효과음을 섞어 `/tmp/poppop-audio-preview.wav`를 만든다. 오프라인 렌더는 소리 존재와 샘플 클리핑 여부를 확인하는 기술 검사이며, 음향의 즐거움이나 다양한 스피커의 청취 품질을 입증하지 않는다. 최종 음량/반복 피로도는 [플레이 테스트 계획](Competitive-Assessment.md)의 실제 사용자 관찰에서 조정한다.

같은 스크립트는 실제 OfflineAudioContext로 bright/soft의 전체·시작10ms·4kHz 이상 대역 RMS를 비교하고 `/tmp/poppop-audio-profile.json`에 기록한다. 소리가 실제로 달라지고 고주파/시작 충격이 줄었는지 확인하는 검사이며 사람의 편안함이나 청력 관련 효능을 주장하지 않는다.
