일일 AI는 위 항목에서 재현된 미완료 내용이 있을 때 하나만 보완한다. 게임 구현 항목이 완료된 현재는 재현 가능한 오류 하나만 새 회귀 테스트와 함께 수정한다. 증거가 없으면 변경 없이 종료한다. 밸런스·새 기능·인프라·의존성·마이그레이션·자동화·기존 테스트를 임의로 변경하지 않는다.

## 이동 수치

고정 산식과 원자료는 [movement-quality.json](evidence/gameplay-upgrade/movement-quality.json)에 있다. 자동 엔지니어링 평가 **99.73/100**이며 사람의 체감 자연스러움·재미 평가가 아니다.

- 위치 연속성: 25/25. 확정 경로 갱신 시 같은 시각의 위치 도약 0.01칸 이내.
- 걸음 위상: 20/20. 진행 중 위상 역행 없음.
- 직선 속도: 20/20. 기준 속도의 ±10% 이내.
- 몸체 연속성: 15/15. 손 움직임 3.5px를 60px 타일로 정규화한 프레임 변화 0.1 이하 비율.
- 실제 Chromium: 19.73/20. AI7 연습전·1280×720·풍성한 효과·키보드 이동 중 10.016초 591개 rAF 간격에서 25ms 이하 비율.

측정은 이 공유 클라우드의 단일 페이지 표본이다. 타일 경계의 위상 초기화 결함을 주입하면 필수 검사가 실패하는 회귀 검사도 포함한다. 느린 기기·다중 탭·운영 네트워크 성능을 보장하지 않는다. 벽 관통 없음·확정 경로 준수·움직임 줄이기 상태 정확성은 점수와 별도 필수 검사다. 기존 85.125점은 다른 설계 평가이므로 이번 점수와 전후 비교하지 않는다.

## 아이템과 접근성

폭탄 수 최대 5, 물줄기 최대 7칸, 신발 1단계(이동 주기 200→100ms)를 유지한다. 물줄기 아이템은 실제 폭발 범위를 늘린다. 설치한 물폭탄의 판정은 설치 시점 능력치를 따르고 이후 획득으로 소급 변경하지 않는다. 보호 핀과 다트도 기존 규칙을 유지한다.

기본 음소거, 음악/효과음 독립 음량을 유지한다. 맵 선택만으로 오디오를 켜지 않는다. 움직임 줄이기/편안한 효과에서는 버블 진입 변형·흔들림·기포·탈출 파편을 제거하고 정적 상태와 구출 표식을 유지한다. 최소 효과는 필수 상태를 유지한다. 핀 방어는 갇힘이나 탈출로 잘못 표시하지 않는다.

1대1·훈련의 기존 지형은 유지하고 4대4 지형만 라군/캔디의 서로 다른 대칭 통로를 추가했다. 기존 시작점의 두 출구·폭발 십자 탈출·중앙 연결·막다른 길/단일 절단점 없음 검사를 유지한다.

## 현재 한계

Unity에는 적용하지 않았다. 실제 Supabase·GitHub Actions 예약 실행·Render 배포는 로컬 브라우저 성공으로 대신하지 않는다. 이 세션은 Git 읽기를 확인했지만 GitHub 관리 API가 Forbidden이라 Actions 변수/secret과 원격 활성화 상태를 확인하지 못했다. 활성화 절차는 [GitHub 자동화](../Operations/GitHub-Automation.md)를 따른다.
