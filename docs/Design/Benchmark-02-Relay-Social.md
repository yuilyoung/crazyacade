# 벤치마크 02: 팝 릴레이와 친구 플레이

평가일: 2026-11-02. 비교 기준은 `9bae5e3`의 **브라우저 POC**다. 이 버전은 비랭크 AI 연습·행동 안내·선택형 BGM/효과음·움직임 줄이기·색 외 팀 단서를 포함한다. 이번 증분은 [팝 릴레이와 친구 플레이 설계](../superpowers/specs/2026-11-02-relay-social-design.md)의 별 운반 목적 모드, 전체 방 설정을 담는 초대 링크, 같은 방 재대결이다. Unity 빌드나 공개 서비스의 완성도로 확대 해석하지 않는다.

**상태: 구현·기술 검증을 반영한 설계 재평가.** 릴레이와 초대·동일방 재대결을 구현하고 아래 실행 근거를 확인했다. 점수는 전달한 기능과 경험을 기준으로 한 잠정 판단이다. 실제 사용자 플레이 테스트는 0명이며, 자동 검사 통과 후에도 재미·차별성·타깃 적합성은 검증할 가설로 남는다.

## 같은 기준으로 비교하기

[기존 비교 평가](Competitive-Assessment.md)의 다섯 항목, 가중치, 네 하위 기준과 순서를 그대로 유지한다. 각 하위 점수는 0~10점이고 항목 점수는 네 값의 단순 평균이다. 가중 종합은 `완성도×0.25 + 재미×0.25 + 독창성×0.20 + 접근성×0.20 + 타깃 적합성×0.10`이다. 점수는 전문가 휴리스틱 평가이며 개발 완료율, 이용자 만족도 또는 시장 점유율이 아니다.

척도도 유지한다. 0은 부재, 2는 큰 진입/사용 장애, 5는 기본 경험이 있으나 공백이 큼, 8은 대체로 일관되고 충분한 경험, 10은 해당 사용 목적에서 뚜렷한 공백이 없는 상태다. 소수점은 계산을 재현하기 위한 것이며 측정 정밀도를 뜻하지 않는다.

| --- | ---: | --- |
| 완성도 | 25% | 핵심 경기의 끝까지 연결 / 콘텐츠와 사용자 흐름 / 오류·상태 경계의 견고함 / 실제 서비스 준비 |

원작 참조는 [크레이지 아케이드 공식 사이트](https://ca.nexon.com/)와 알려진 PC 설치형 버블 대전의 정체성을 바탕으로 한 이전 문서의 참조상을 유지한다. 이번에 최신 원작 클라이언트를 실행하거나 공식 사이트를 조사하지 않았다. 현행 콘텐츠·접근성·운영 품질을 새로 검증한 비교가 아니므로 원작의 점수를 올리거나 내리지 않는다.

## 이번 증분에서 구분할 가치

**팝 릴레이:** 기존 클래식을 유지하면서 팀전의 승리 목표를 별 3회 운반 또는 제한시간 종료 시 높은 운반 점수로 바꾼다. 별은 하나이며 피격·탈락·연결 종료 시 떨어지고, 득점 뒤 재등장한다. 탈락자는 안전한 시작 지점으로 복귀한다. 이 규칙은 위험을 감수한 운반, 동료 구출, 상대 차단을 연결할 가능성이 있다. 캡처·운반 목적 모드는 알려진 게임 장르의 방식이며 “세계 최초”나 핵심 버블 전투의 발명을 주장하지 않는다. 해당 조합이 기억할 만한 제품 경험인지 아직 확인하지 않았다.

**친구 초대:** 방 이름뿐 아니라 `room`, `mode`, `map`, `items`, `rules`를 전달해 상대가 같은 선택을 채울 수 있게 한다. 상대는 설정을 확인하고 직접 입장한다. 이름·토큰·키는 링크에 포함하지 않으며 연습방은 공유하지 않는다. 이는 설정 실수를 줄이는 흐름이며 자동 매칭, 인증 완료, 인원 확보 또는 인터넷 배포 완료와는 별개의 범위다.

**같은 방 재대결:** 연결된 모든 사람이 준비하면 소켓·플레이어 ID·팀·외형·방 설정을 유지하고 새 라운드를 준비한다. 정원이면 시작하고 부족하면 새 참가자를 기다린다. 전투 상태와 라운드 결과는 초기화하고 이전 경기 저장용 스냅샷은 보존해야 한다. 끊어진 연결을 되살리는 재접속 기능은 아니다. 연습은 기존처럼 새 개인방에서 바로 다시 시작한다.

## 플레이 테스트에서 확인할 위험

주 타깃은 **설치 없이 웹에서 친구와 짧게 한두 판 즐기고, 기다리는 동안 연습하고 싶은 캐주얼·초보 사용자**다. 보조 타깃은 버블 대전 경험이 있고 짧게 다시 즐기려는 사용자다. 기기·장르 경험·친구 동행 여부·세션 길이로 모집한다. 성별이나 나이를 이유로 귀여운 그림·쉬운 난이도·경쟁 선호를 추정하지 않는다.

**현재 참여자 0명, 관찰 결과 없음.** 기존 5명 계획은 첫 진입과 링크·설정 이해를 찾는 데 재사용할 수 있지만 인간 4대4 협력·밸런스를 입증하지 못한다. 실제 친구 8명이 참여하는 별도 세션에서 클래식과 릴레이를 번갈아 플레이하고 순서를 나누어 학습 효과를 기록한다. 아래 항목은 확인할 위험과 측정 방법이며 발견한 결함이나 달성 결과가 아니다.

## 다음 우선순위

1. **비공개 초대 테스트를 위한 실제 배포와 운영 연결:** 호스트·도메인·TLS, 게스트 차단, 실제 Supabase 인증·마이그레이션·저장, 오류 관측을 확인해 서로 다른 기기의 친구가 실제로 만나는 흐름을 검증한다. 이번 문서는 이 작업이 완료되었다고 주장하지 않는다.
2. **연결 끊김과 대기 복구:** 재접속·자리 복구·중복 접속 정책과 결과/저장 실패 처리부터 설계·검증한다. 같은 소켓을 유지하는 재대결은 네트워크가 끊긴 참가자를 복구하지 못한다. 모집·전원 준비 대기가 실제 주요 이탈 원인인지 관찰한 뒤 대기 흐름도 보완한다.
3. **인간 4대4 밸런스와 목적 안내 조정:** 지도 경로·기지 대기·복귀 보호·성장 유지·역전 가능성을 관찰한 뒤 수정한다. 이후에 고유 맵 기믹과 숙련자 변주를 추가한다. 새 모드·아이템 수를 먼저 늘려 검증 공백을 덮지 않는다.

다음 평가는 같은 다섯 항목과 가중치로 시행하고, 기술 검사와 사용자 관찰에 따라 점수를 내릴 수도 있다. 원작의 최신 상태와 직접 비교하려면 동일 기기·동일 과제를 정한 별도 조사를 먼저 수행한다.
