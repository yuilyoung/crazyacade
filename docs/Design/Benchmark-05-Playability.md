# 벤치마크 05: 친구와 시작하고 직접 배우기

평가일: 2026-11-03. 기준 버전은 `874128e`의 **브라우저 POC**이며 [벤치마크 04](Benchmark-04-Result-Storage.md)의 결과 저장 복구까지 포함한다. 이번 증분은 [플레이 흐름 설계](../superpowers/specs/2026-11-03-playability-design.md)의 친구+AI 팀전, 실제 조작으로 통과하는 네 단계 훈련, 키 변경·고대비·왼손 터치 배치와 사건 자막이다.

**상태: 구현·기술 검증을 반영한 독립 설계 재평가.** 구현을 맡지 않은 AI 평가자가 고정 기준, 최종 소스, 실행 로그와 실제 Chromium 화면을 확인했다. 최종 평가값은 **70/100**으로 반올림 없이 목표에 도달했다. 아래 점수는 독립 AI 에이전트의 휴리스틱 설계 판단이며 실제 이용자 평가나 개발 완료율이 아니다. 실제 사용자 플레이 테스트는 **0명**이다. 최초 평가 68.75와 후속 평가 69.75에서 발견한 공백, 추가 구현과 재검증도 아래에 보존한다.

## 고정 기준

[최초 비교 평가](Competitive-Assessment.md)의 다섯 항목과 가중치, 네 하위 기준의 순서, 0~10 척도를 그대로 유지한다. 각 항목은 네 하위 점수의 단순 평균이다. 가중 종합은 `완성도×0.25 + 재미×0.25 + 독창성×0.20 + 접근성×0.20 + 타깃 적합성×0.10`이다. 0은 부재, 2는 큰 진입·사용 장애, 5는 기본 경험과 큰 공백, 8은 대체로 일관되고 충분한 경험, 10은 해당 목적에서 뚜렷한 공백이 없는 상태다. 소수점은 계산 재현을 위한 것이며 실측 정밀도를 뜻하지 않는다.

| 항목 | 비중 | 하위 기준 순서 |
| --- | ---: | --- |
| 완성도 | 25% | 핵심 경기의 끝까지 연결 / 콘텐츠와 사용자 흐름 / 오류·상태 경계의 견고함 / 실제 서비스 준비 |
| 재미 | 25% | 설치·회피·연쇄의 순간 판단 / 팀 협력과 구조 / 전략·반복 플레이 변주 / 행동 결과의 피드백 |
| 독창성 | 20% | 독자 시각·캐릭터 정체성 / 규칙의 차별성 / 기억할 수 있는 제품 약속 / 이용 방식의 차별성 |
| 접근성 | 20% | 처음 경기 시작·학습 / 입력 수단 / 정보 가독성·색 외 단서 / 움직임·소리 조절 |
| 타깃 적합성 | 10% | 짧은 세션 / 친구와 함께하기 / 초보자가 연습·실패 후 다시 하기 / 웹·모바일 사용 맥락 |

원작의 최신 클라이언트와 운영 상태는 이번에도 조사하지 않았다. 기존 크레이지 아케이드 참조값 **7.4375/10**을 유지하며 현행 원작의 실측 평가로 해석하지 않는다.

## 중간 평가와 실제 보완

첫 구현은 기능이 동작하더라도 훈련의 발견·종료 후 이동, 모바일 사건 전달과 작은 표식의 공백이 남아 **68.75**로 평가했다. 당시 점수와 계산을 보존한다.

| 항목 | `874128e` 하위 점수 | 이전 평균 | 1차 하위 점수 | 1차 평균 | 가중 기여 |
| --- | --- | ---: | --- | ---: | ---: |
| 완성도 | 8 / 7 / 7.5 / 4 | 6.625 | 8 / 7.5 / 7.5 / 4 | 6.75 | 1.6875 |
| 재미 | 7 / 8 / 7 / 6.5 | 7.125 | 7 / 8 / 7 / 7 | 7.25 | 1.8125 |
| 독창성 | 6 / 5.5 / 6.5 / 5 | 5.75 | 6 / 5.5 / 6.5 / 5 | 5.75 | 1.15 |
| 접근성 | 7 / 7 / 6.5 / 5 | 6.375 | 8 / 8 / 7.5 / 5 | 7.125 | 1.425 |
| 타깃 적합성 | 8 / 7.5 / 7.5 / 7.5 | 7.625 | 8 / 8 / 8 / 8 | 8 | 0.8 |
| **가중 종합 / 10** | | **6.625** | **1.6875 + 1.8125 + 1.15 + 1.425 + 0.8** | **6.875** | **6.875** |

1차 평가 뒤 첫 화면의 훈련·AI 연습·친구 팀전 선택, 단계마다 직접 시작하는 설명 화면, 완료 후 AI 연습/친구 설정으로 이어가기, 경기장 안의 최신 사건 안내를 추가했다. `/tmp/poppop-playability-full-final.log`의 **224/224** 서버 검사와 `/tmp/poppop-playability-final.log`의 실제 Chromium 경로를 확인했다. 선택한 캔디 맵이 훈련 이후에도 유지되고, 구조 설명을 읽는 동안 대상의 10초 타이머가 멈추며, 무음 사건 안내가 모바일 경기장 안에 보인다. 전체 훈련의 180초 상한은 계속 흐른다.

이 증거로 콘텐츠·흐름 7.5→8, 행동 결과의 피드백 7→7.5, 처음 시작·학습 8→8.5, 초보의 실패 후 다시 하기 8→8.5를 인정했다. 나머지는 유지해 두 번째 평가는 **69.75/100**이다. 계산은 `6.875×0.25 + 7.375×0.25 + 5.75×0.20 + 7.25×0.20 + 8.125×0.10 = 6.975`이며 목표 70점으로 올림하지 않는다.

독립 시각 점검에서 모바일 피격 후 하단 조작이 화면 밖으로 밀리는 문제를 추가 발견했다. 기존 검사는 피격 전 버튼 범위만 확인했다. 피격 후에도 모든 조작을 검사하도록 보완한 실행(`/tmp/poppop-mobile-red.log`)에서 왼쪽 버튼의 하단이 **846.5625px**로 844px 화면을 넘는 실패를 재현했다. 또한 모바일 캔버스의 작은 팀 문자·본인·구조 시간 표식은 여전히 읽기 어려워 정보 가독성을 7.5로 유지했다.

최종 구현은 하단 상태 글이 늘어도 버튼을 아래로 밀지 않도록 배치하고, 캔버스의 CSS 표시 비율에 맞춰 핵심 표식을 확대했다. 원형 B·마름모 P, 본인의 ‘나’, 아군 구조의 불투명 `+남은 초` 표식이 서로 구분된다. 실제 모바일 훈련의 아군 구조 단계와 본인 피격 이미지를 다시 확인했고, 정상/피격 상태 모두 여섯 조작이 화면 안에 있으며 핵심 표식 글자 10 CSS px 이상·팀 표식 12 CSS px 이상임을 브라우저에서 확인했다(`/tmp/poppop-mobile-green.log`). 이제 정보 가독성 **7.5→8**을 인정해 **69.75→70**이 된다. 버튼 넘침 수정은 기존 모바일 점수 8을 유지할 근거이며 별도 가산하지 않았다.

## 남은 개선과 사용자 검증

자동 검사와 시각 점검에서 발견한 진입·이어가기·타이머·작은 표식·피격 후 조작 배치의 문제는 이번 구현에 반영했다. 남은 우선순위는 **실제 초보의 학습 전이**, **다기기 친구 플레이와 밸런스**, **실제 서비스 연결**이다. 네 단계 훈련에는 릴레이 목적·연쇄 판단을 연습하는 단계가 없고, 전체 180초 상한은 설명을 읽는 동안에도 흐른다. 확대된 표식이 밀집한 인간 경기에서 정보를 가리지 않는지와 한 줄 사건 안내의 말줄임도 관찰할 필요가 있다.

**실제 참가자 0명, 관찰 결과 없음.** 다음 초보 관찰에서는 훈련을 스스로 찾는 비율, 설명을 읽다가 구조 제한시간이 끝난 횟수, 네 단계의 무도움 완료, 훈련에서 일반 경기로 넘어간 뒤 첫 회피·구출 성공, 소리 없이 주요 사건을 설명하는지 기록한다. 친구 두 명의 시작·팀 선택·재대결 과제와 실제 모바일 화면/조작을 함께 확인한다. 자발적 재경기 선택과 재미 점수는 강제 실행한 자동 테스트와 구분한다.

실제 Supabase·공개 HTTPS/WSS 서비스, Unity 빌드, 인간 4대4 밸런스, 장시간 운영과 다양한 실제 기기의 검증 공백은 유지한다. 설계 평가 70점 도달이 이 검증을 완료했다는 뜻은 아니다. 관찰 근거가 부족하거나 실제 문제가 확인되면 같은 기준에서 점수를 유지하거나 낮춘다.
