# 키보드 입력 응답 100ms 개선

사용자 요청: 스케줄러보다 게임 기능 개선을 먼저 수행한다. 입력 후 화면 이동 시작까지 100ms 이하를 실제 브라우저에서 측정한다. 기존99.73 점수는 입력 응답이나 사람의 자연스러움 평가가 아니며 이번 요구의 증거로 사용하지 않는다.

원인: 키 입력은 즉시 전송되지만 표현 타임라인은100ms 서버 틱에서 이동을 확정한 뒤에야 시작한다. 반복 입력은80ms 간격이다. 서버 판정과 표현을 분리해 내 캐릭터만 로컬의 안전한 한 칸을 먼저 표시한다. 서버의 좌표·충돌·아이템·폭탄·승패는 변경하지 않는다.

구현: 별도 local-movement 모듈에서 한 칸 예측, 확정 응답과의 연속 연결, 거절/새 장애물/300ms 수신 공백 시 복구, 코너 보존, 재접속·장면·설정·포커스 변경 초기화를 담당한다. renderer는 내 캐릭터 포즈에만 적용한다. 줄인 모션/최소 효과는 기존 서버 확정 위치를 유지한다. 입력 전송 빈도를 높여 서버의 제한을 우회하지 않는다.

검증: 실패하는 회귀 테스트를 먼저 작성한다. 실제 키 입력→WebSocket 전송→서버 확정→Canvas의 내 표식 위치 변화 시간을 각각 관찰한다.20회 이상 측정해p50/p95/최대를 보고한다. 길게 누름·방향 전환·벽·거절·스테일·갇힘·모달 회귀를 포함한다. 로컬/시험 네트워크 수치와 운영망의 미검증 한계를 구분한다. 기존 전체 테스트와 게임 기능 브라우저 검사를 유지한다.


## 사용자 평가와 점수의 구분

사용자는 넥슨 크레이지 아케이드 대비 현재 서비스가50점 미만이라고 평가했다. 이 평가는 존중하며 이전 합성 이동 점수로 반박하지 않는다. 품질 게이트의90/100은 명시한 자동 검사 통과 기준이며 원작 대비 미술·재미·조작감90점이 아니다. 사람의 플레이 비교 평가는 미검증이다.

## 변경 사항

내 캐릭터의 입력 반응만 예측하며 최대 한 칸의 미확정 이동을 표시한다. 실제 판정·아이템·폭발·승패는 서버가 소유한다. 확인 응답에서 같은 이동을 두 번 재생하지 않는다. 반환·방향 교체·조기 확정·수신 공백·장면 변경·갇힘·죽음·포커스와 모션 설정에 대한 회귀 검사를 추가했다. 직각 경로의 남은 코너를 유지하며 재접속 시 과거 예측을 지운다.

물줄기 아이템을 실제로 주운 뒤 설치한 물폭탄의 서버range가3→4로 증가하는 wire 검사를 추가했다. 물폭탄 몸체는 능력치에 따라 최대8% 커지고, 퓨즈 표시와 별도로 실제 범위 숫자가 보인다. 효과·스킨·고대비·모션 줄이기의 기존 의미를 유지한다.

## 품질 게이트와 남은 네트워크 조건

전체 명령은 `python3 scripts/check-quality-gates.py --all`이다. 10영역×10점, 최소90점과 필수 검사 조건을 모두 만족해야 통과한다. 부족한 결과를 건너뛰거나 과거 결과로 점수를 채우지 않는다.

현재 클라우드의 허용 도메인에 없는 `cdn.playwright.dev`, `playwright.download.prss.microsoft.com`에서 Firefox/WebKit 설치가403으로 거부되었다. 필요한 도메인을 환경 설정 초안에 추가했다. GitHub CI 확인에 필요한 `api.github.com`도 추가했다. 초안 저장은 현재 네트워크 적용·배포를 뜻하지 않는다. 3엔진 검사가 실제 통과하기 전에는 전체 게이트를 통과했다고 표시하지 않는다.

동일한 브라우저 관측기를 사용해 기존ebc5a28과 변경본을 각각36회 측정했다. 모두 실제 trusted 키 입력이며 길게 누르기·6회 반전·직각 코너를 포함한다.

| 변경 로컬 | 18.9 | 23.7 | 26.0 |

새 로컬 표본은36/36이100ms 이내이고 누락은0이다. 측정 중 런타임 소스 변경도 없다. [표본·소스 해시](evidence/input-response/input-latency.json)를 보관한다. 서버 확정은 로컬 최대169.2ms로 화면 예측과 구분하며 서버가100ms 이내에 항상 판정한다고 주장하지 않는다. 이 표본은 실제 인터넷 전체나 물리 디스플레이 지연을 보장하지 않는다. 한 칸 예측의 확인 대기 때문에 방향 반전 중 일시적인 이동 간격이 남을 수 있으며, 최초 반응 시간 개선을 전체 애니메이션의 완전한 매끄러움으로 확대하지 않는다.

Node696개, 타임라인/로컬 표현45개 관련 검사,3D가 아닌 Canvas 실제 UI, 실제 아이템 range3→4, 전체 게임/회원 E2E와64접속/8룸/60초 부하가 통과했다. 독립 검토에서 발견한 반환/코너/확정 타이밍 문제는 회귀 검사로 고쳤다. 추가 무작위1000경로·100만 표본 검토에서 대각선 이동과 최종 권위 위치 불일치는 발견되지 않았다.

전체 게이트의 로컬 점수는 **92.5/100**이나 **필수 브라우저 검사가 실패하여 합격이 아니다**. Chromium 새로고침/재개는 통과했지만 Firefox/WebKit 설치 차단으로 전체3엔진 검사는 실패했다. [현재 게이트 보고서](evidence/input-response/quality-report.json). CI는3엔진을 설치해 같은 검사를 실행하며 실패하면 통과 처리하지 않는다.
