# 4대4 버블 대전 POC 완료 기준

이 POC는 독자 캐릭터를 쓰는 브라우저와 Unity 클라이언트가 같은 Node.js 권위 서버에 접속하는 게임이다. POC의 플레이 검증 경로는 브라우저다. Unity 빌드와 실제 Supabase 전적 저장 검증은 별도이다.

## 실행과 검증

- `cd Server && npm ci && npm run poc`: 로컬 개발 게스트 접속을 허용하고 브라우저 클라이언트를 같은 포트에 제공한다. 기본 포트 8080, 기본 바인딩 127.0.0.1. 별도 터미널·브라우저 탭 8개에서 같은 방에 접속한다.
- `cd Server && npm test`: 서버 단위 및 실제 HTTP/WebSocket 통합 테스트.
- 저장소 루트에서 `node --test Assets/Tests/*.test.cjs`: Unity의 JavaScript 브리지 테스트.
- `python3 scripts/browser-smoke.py`: Python Playwright와 Chromium이 있는 환경에서 임시 서버와 8개 브라우저 세션을 실행하여 실제 참가·선택·키보드·물폭탄·다트 습득·원거리 구조·점수·랭킹·승패와 모바일 기본전·화면 폭을 검증한다. 결과 이미지는 `/tmp/poppop-poc-*.png`, `/tmp/poppop-service-*.png`에 생성한다. 테스트 전용 드롭 시드를 사용해 실제 블록 파괴부터 다트 습득까지 반복 검증한다.
- `python3 scripts/practice-smoke.py`: 게스트 차단 상태에서 실제 AI 연습 한 판과 다시 시작, 조작 안내·설정·모바일을 검사한다. 결과는 `/tmp/poppop-practice-*.png`.
- `python3 scripts/relay-smoke.py`: 초대 링크 설정 일치·8인 릴레이 운반/구출/득점·비랭크·동일방 재대결과 모바일AI를 검사한다. 이미지 `/tmp/poppop-relay-*.png`.
- `python3 scripts/reconnect-smoke.py`: 실제 브라우저 단절·자동 복귀·같은 탭 새로고침·명시적 나가기와 모바일 연결 상태를 검사한다. 이미지 `/tmp/poppop-reconnect-*.png`.
- `python3 scripts/reconnect-auth-smoke.py`: 저장소가 차단된 실제 브라우저와 로컬 인증 provider로 동일 익명 계정 복귀·JWT 재검증·profile 중복 쓰기 방지를 검사한다.
- `python3 scripts/audio-smoke.py`: 실제 브라우저 오디오 제어와 오프라인 합성을 검사하고 `/tmp/poppop-audio-preview.wav`를 만든다.
- `python3 scripts/test-rankings-db.py`: Docker의 일회용 PostgreSQL에서 스키마·마이그레이션·결과 집계·권한을 검사한다.
- `python3 -m unittest discover -s .github/scripts -p 'test_*.py'`: AI 변경 경로 보호 검사.

브라우저 smoke 검사는 개발 게스트 또는 로컬 인증 fixture를 사용하며 외부 Supabase를 사용하지 않는다. 운영에서는 `ALLOW_DEV_GUESTS=false`, Supabase 익명 로그인, 서버 인증 및 TLS가 필요하다. 서비스 역할 키는 `/api/config`에 포함되지 않는다. 동작을 검증하지 않은 Unity 빌드나 실제 Supabase 적용을 이 검사 결과로 대신하지 않는다.

## 연결 복구 증분 검증
