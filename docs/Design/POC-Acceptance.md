# 4대4 버블 대전 POC 완료 기준

이 POC는 독자 캐릭터를 쓰는 브라우저와 Unity 클라이언트가 같은 Node.js 권위 서버에 접속하는 게임이다. POC의 플레이 검증 경로는 브라우저다. Unity 빌드와 실제 Supabase 전적 저장 검증은 별도이다.

| 사용자 목표 | 동작 기준 | 확인 방법 |
| --- | --- | --- |
| 캐릭터 및 맵 선택 | 캐릭터 4종과 맵 3종을 선택하고 같은 맵으로 참가 | 카탈로그·선택 통합 테스트, 브라우저 참가 테스트 |
| 캐릭터 스킨 적용 | 스킨 3종을 선택하면 서버 상태와 캐릭터 외형에 반영 | 선택 통합 테스트, 브라우저 상태 및 화면 확인 |
| 대전 인원수 적용 | 4대4는 8명, 1대1은 2명에 시작. 초과 참가와 중복 계정 거부 | 실제 WebSocket 방 테스트 및 브라우저 8세션 |
| 물폭탄 및 구출 | 물폭탄 2초 후 4방향 파동·연쇄 반응, 버블 2초 후 탈락, 아군 접근 구출 | 실제 WebSocket·브라우저 키보드 테스트 |
| 아이템전 | 블록 파괴 시 아이템, 획득 시 최대 설치 수/파동 범위/대시/핀 효과 | 아이템 규칙 테스트 및 서버 상태 렌더링 |

## 실행과 검증

- `cd Server && npm ci && npm run poc`: 로컬 개발 게스트 접속을 허용하고 브라우저 클라이언트를 같은 포트에 제공한다. 기본 포트 8080, 기본 바인딩 127.0.0.1. 별도 터미널·브라우저 탭 8개에서 같은 방에 접속한다.
- `cd Server && npm test`: 서버 단위 및 실제 HTTP/WebSocket 통합 테스트.
- 저장소 루트에서 `node --test Assets/Tests/*.test.cjs`: Unity의 JavaScript 브리지 테스트.
- `python3 scripts/browser-smoke.py`: Python Playwright와 Chromium이 있는 환경에서 임시 서버와 8개 브라우저 세션을 실행하여 실제 참가·선택·키보드·물폭탄·구조·승패와 모바일 화면 폭을 검증한다. 결과 이미지는 `/tmp/poppop-poc-*.png`에 생성한다.

브라우저 smoke 검사는 외부 Supabase를 사용하지 않는 개발 게스트 검사다. 운영에서는 `ALLOW_DEV_GUESTS=false`, Supabase 익명 로그인, 서버 인증 및 TLS가 필요하다. 서비스 역할 키는 `/api/config`에 포함되지 않는다. 동작을 검증하지 않은 Unity 빌드나 실제 Supabase 적용을 이 검사 결과로 대신하지 않는다.

## 확인한 결과 (2026-11-02)

- 서버 테스트 35개 통과: 인증·입장·선택·아이템·HTTP 공개 설정·입력 처리·경기 기록 전송.
- 실제 Chromium 8세션 통과: 4대4 배정, 캐릭터/스킨, 키보드 이동·물폭탄·아군 구출·팀 결과, 초과 입장 거부 및 다시 준비.
- 모바일 Chromium 터치 이동·물폭탄, 라군 맵 참가와 화면 폭 검사 통과.
- Unity JavaScript 브리지 테스트 파일 2개 통과.
- 실제 Supabase 연결/마이그레이션, Unity C# 컴파일 및 WebGL 빌드는 검증하지 않았다. 브라우저 POC는 개발 게스트 모드로 검증했다.
