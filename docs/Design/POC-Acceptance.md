# 4대4 버블 대전 POC 완료 기준

이 POC는 독자 캐릭터를 쓰는 브라우저와 Unity 클라이언트가 같은 Node.js 권위 서버에 접속하는 게임이다. POC의 플레이 검증 경로는 브라우저다. Unity 빌드와 실제 Supabase 전적 저장 검증은 별도이다.

| 사용자 목표 | 동작 기준 | 확인 방법 |
| --- | --- | --- |
| 캐릭터 및 맵 선택 | 캐릭터 4종과 맵 3종을 선택하고 같은 맵으로 참가 | 카탈로그·선택 통합 테스트, 브라우저 참가 테스트 |
| 캐릭터 스킨 적용 | 스킨 3종을 선택하면 서버 상태와 캐릭터 외형에 반영 | 선택 통합 테스트, 브라우저 상태 및 화면 확인 |
| 대전 인원수 적용 | 4대4는 8명, 1대1은 2명에 시작. 초과 참가와 중복 계정 거부 | 실제 WebSocket 방 테스트 및 브라우저 8세션 |
| 물폭탄 및 구출 | 물폭탄 2초 후 4방향 파동·연쇄 반응, 버블 2초 후 탈락, 아군 접근 구출 | 실제 WebSocket·브라우저 키보드 테스트 |
| 아이템전 | 아이템전 ON/OFF, 최대 설치 수/파동 범위/이동속도/핀/다트 효과 | 아이템 규칙·모드 불일치 검사, 브라우저 다트 습득·원거리 구출 |
| 점수·랭킹 | 경기 점수판, 상위 50명 등급·승무패, 서버 전용 집계 | HTTP·브라우저 검사 및 실제 PostgreSQL 회귀 검사 |
| 맵 블록 스킨 | 정원·라군·캔디의 벽/파괴 블록 이미지 6종 | SVG 검사 및 실제 Chromium 화면 확인 |

## 실행과 검증

- `cd Server && npm ci && npm run poc`: 로컬 개발 게스트 접속을 허용하고 브라우저 클라이언트를 같은 포트에 제공한다. 기본 포트 8080, 기본 바인딩 127.0.0.1. 별도 터미널·브라우저 탭 8개에서 같은 방에 접속한다.
- `cd Server && npm test`: 서버 단위 및 실제 HTTP/WebSocket 통합 테스트.
- 저장소 루트에서 `node --test Assets/Tests/*.test.cjs`: Unity의 JavaScript 브리지 테스트.
- `python3 scripts/browser-smoke.py`: Python Playwright와 Chromium이 있는 환경에서 임시 서버와 8개 브라우저 세션을 실행하여 실제 참가·선택·키보드·물폭탄·다트 습득·원거리 구조·점수·랭킹·승패와 모바일 기본전·화면 폭을 검증한다. 결과 이미지는 `/tmp/poppop-poc-*.png`, `/tmp/poppop-service-*.png`에 생성한다. 테스트 전용 드롭 시드를 사용해 실제 블록 파괴부터 다트 습득까지 반복 검증한다.
- `python3 scripts/practice-smoke.py`: 게스트 차단 상태에서 실제 AI 연습 한 판과 다시 시작, 조작 안내·설정·모바일을 검사한다. 결과는 `/tmp/poppop-practice-*.png`.
- `python3 scripts/audio-smoke.py`: 실제 브라우저 오디오 제어와 오프라인 합성을 검사하고 `/tmp/poppop-audio-preview.wav`를 만든다.
- `python3 scripts/test-rankings-db.py`: Docker의 일회용 PostgreSQL에서 스키마·마이그레이션·결과 집계·권한을 검사한다.
- `python3 -m unittest discover -s .github/scripts -p 'test_*.py'`: AI 변경 경로 보호 검사.

브라우저 smoke 검사는 외부 Supabase를 사용하지 않는 개발 게스트 검사다. 운영에서는 `ALLOW_DEV_GUESTS=false`, Supabase 익명 로그인, 서버 인증 및 TLS가 필요하다. 서비스 역할 키는 `/api/config`에 포함되지 않는다. 동작을 검증하지 않은 Unity 빌드나 실제 Supabase 적용을 이 검사 결과로 대신하지 않는다.

## 확인한 결과 (2026-11-02)

- 서버 및 클라이언트 로직 테스트 88개 통과: 인증·입장·선택·아이템·HTTP 공개 설정·입력 처리·다트·이동속도·점수·랭킹·경기 기록 전송·AI 경로/위험 회피·연습 격리/인증/정리·안내·오디오 생명주기.
- 실제 Chromium 8세션 통과: 4대4 배정, 캐릭터/스킨, 키보드 이동·물폭탄·아군 구출·다트 습득/원거리 구출·점수판·랭킹·팀 결과, 초과 입장 거부 및 다시 준비.
- 모바일 Chromium 터치 이동·물폭탄, 아이템전 OFF·라군 맵 참가와 화면 폭 검사 통과.
- Unity JavaScript 브리지 테스트 파일 2개 통과.
- 실제 PostgreSQL 17에서 스키마·마이그레이션·승패/무승부·중복 집계 방지·트랜잭션 롤백·랭킹 쓰기 권한 검사 통과.
- GitHub AI 변경 경로 보호 5개 통과. Docker 빌드 및 비루트 실행·HTTP/음악 모듈·사람 대전 게스트 차단·비랭크7봇 연습 검사 통과.
- 프로덕션 게스트 차단 상태에서 Chromium 1인+AI 7명 연습·실제 조작 안내·모바일 기본전·한 판 종료·즉시 재연습·일반 대전 인증 유지 검사 통과.
- Chromium 실제 Web Audio의 사용자 클릭 전 컨텍스트 미생성, 독립 음악/효과음·음량, 음소거·탭 숨김·브라우저 오디오 중단/복구·새로고침 동작 확인. 모바일390×844에서 조작 버튼이828px 안에 표시되며 구조 알림이 버튼 위치를 바꾸지 않음. 8마디 음악+효과음 WAV 렌더링은 약 15.6초, 피크 0.25로 클리핑 없음. 실제 사용자 음향 선호/재미 평가는 별도.
- 연습방 포화 상태의 나가기/재입장 경합을 재현해 수정: 수정 전 스트레스 40회 중 16회 실패, 수정 후 40회 모두 통과. 지연된 이전 방 정리가 새 방을 제거하지 않는 회귀 검사 포함.
- 실제 Supabase 프로젝트 연결/마이그레이션 적용, Unity C# 컴파일 및 WebGL 빌드는 검증하지 않았다. 브라우저 POC는 개발 게스트 모드로 검증했다.
