# 4대4 팀전 개발 목표

이 프로젝트는 기존 Pop Pop Arena의 독자적인 캐릭터와 에셋을 유지하면서 온라인 팀전으로 확장한다. 서버가 게임 결과를 결정하고 클라이언트는 입력과 화면 표시를 담당한다. 기존 Supabase 익명 인증과 서버 전용 서비스 역할 키 경계를 유지한다.

## 완료 기준

- 8명이 같은 방에 입장하고 4명씩 두 팀을 이뤄 게임을 시작한다. 인원 부족, 중복 입장, 퇴장과 동시 입장을 처리한다.
- 경기 전 캐릭터, 사용 가능한 스킨, 맵을 선택하고 서버가 선택을 검증해 모든 참가자에게 전달한다. 캐릭터와 스킨은 공정한 대전을 위해 외형에만 영향을 준다.
- 맵별 시작 지점과 이동 가능한 타일을 검증하고, 모든 참가자가 같은 맵을 본다.
- 서버가 오브 설치, 파동, 아이템 생성 및 획득, 버블, 아군 구조, 탈락과 팀 승패를 판정한다. 아이템별 효과와 최대치는 구현 시 명시하고 자동 테스트한다.
- 온라인 입력, 8명 렌더링, 상태 표시와 결과 화면을 WebGL에서 검증한다. 경기 결과는 인증된 사용자 기준으로 저장한다.

## 작업 순서

1. 인증과 방 입장 경계를 보강하고 실제 WebSocket 통합 테스트를 갖춘다.
2. 방 로비, 팀 배정, 8인 시작 조건과 퇴장·동시 입장을 구현한다.
3. 맵 및 캐릭터·스킨 선택을 서버와 클라이언트에 연결한다.
4. 서버 권위 아이템, 버블 구조 및 팀 승패를 구현한다.
5. Unity WebGL 빌드와 8개 클라이언트의 실제 대전을 검증하고 배포 지침을 정리한다.

현재 저장소의 1대1 MVP가 위의 완료 기준을 충족한다는 뜻은 아니다. Supabase 설정과 Unity 편집기 및 WebGL 빌드 환경은 실제 통합 검증에 필요하다.
