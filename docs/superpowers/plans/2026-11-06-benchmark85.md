# Benchmark85 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. 단계별 소유권을 지키고 변경·검증을 보고한다. 커밋과 통합은 root만 수행한다.

**Goal:** 서버 권위 등급 매칭·파티 재경기·운영 동시성 보강을 구현하고 같은 기준85점을 독립 검증한다.
**Architecture:** 동기 경기 상태 소유와 비동기 I/O 경계를 유지한다. 매칭·파티·admission·outbox lease는 별도 계약으로 분리하고 index는 수명·인증·네트워크를 조립한다. 브라우저는 읽기 전용 VM으로 상태를 투영한다.
**Tech Stack:** Node22+/ws, browser ES modules/Canvas/Web Audio, Linux Docker/flock, Supabase PostgreSQL.
**Spec:** ../specs/2026-11-06-benchmark85-design.md

- 기준c41ce044, worktree /workspace/crazyacade-benchmark85, main은 검증 전 변경하지 않는다. 기존 full-auto/원격 반영 승인을 따른다.
- 구현 상수·수명은 spec의4auth/32pending,256connections/64rooms/128queue,30rate/60burst,64KiB·256KiB/3초,130초drain,매칭100+50/15초·400상한·180초,파티3판을 따른다.
- 클라이언트 등급/목표/점수 신뢰 금지. 랭크 봇 충원 금지. 기존 인터페이스 기본값과 classic/relay/harmony/training/복귀/결과 저장을 보존한다.
- 실제 서비스 연결·원작 현행 클라이언트·인간 재미를 검증한 것으로 주장하지 않는다. 루브릭20개·가중치 고정.

구현·회귀·실제 SQL·컨테이너·공식 로컬 부하는 검증했다. 고정 기준 독립 평가는84.625/100이며85목표는 미달이다. 실제 Supabase·공개 배포/복구·인간 플레이 증거의 공백을 남은 서비스 과제로 기록한다. 점수를 올림하거나 테스트 개수만으로 가산하지 않는다. 원격 반영은 검증한 증분을 보존하는 절차이며85달성 주장이 아니다.
