# Motion85 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. 파일 소유권·검토·실행 증거를 지키고 root만 통합·원격 반영한다.

**Goal:** 브라우저 전투의 걷기·폭발·상태 변화 모션을 실제 플레이에 연결하고 같은 기준85점 목표를 검증한다.
**Architecture:** 읽기 전용 서버 snapshot → 표현 타임라인 → 벡터 캐릭터/이펙트 렌더러. 서버 판정과 입력은 유지한다.
**Tech Stack:** 기존 Node/ws, browser Canvas2D, Playwright. 새 제품 의존성 없음.
**Spec:** ../specs/2026-11-06-motion85-design.md

## Global Constraints
- 기준4f647ef, 작업경로 /workspace/crazyacade-motion85, branch feat/motion85. main은 검증 후 fast-forward한다.
- 서버·DTO·게임 판정·입력·랭킹·파티 규칙 변경 금지. 공유 인터페이스와 시간/정원은 spec을 따른다.
- snapshot 불변성, 재접속 baseline, 한 칸 이동80ms, 수신 공백300ms, 선수8/사건128/타일143 상한.
- full만 운동 효과, calm/reduced는 정적 사건 표식, minimal은 필수 상태만. 화면 섬광/카메라 흔들림/강제 소리 없음.
- 새 자산/엔진 의존성 없이 기존 캐릭터·착장·모바일·고대비·결과 카드를 보존한다. 자동검증은 인간 실험이 아니다.

## Review Focus
- 네트워크 복귀/오래된 tick/새 경기에서 과거 폭발·구출을 재생하지 않음.
- 짧은 연속 방향 전환이 대각선으로 벽을 뚫는 표시를 만들지 않음.
- 탈락 잔상이 살아 있는 선수처럼 보이거나 위험 셀이 시각적으로 지연되지 않음.
- 전투 중 설정 변경과 숨김/재개가 오래된 효과를 재생하거나 큐를 키우지 않음.
