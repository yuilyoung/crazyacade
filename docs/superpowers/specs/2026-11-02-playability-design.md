# 플레이 접근성·재미 고도화 설계

사용자 요청: 기존 크레이지 아케이드와 완성도·재미·독창성·접근성·타겟 적합성을 비교/점수화하고 다음 고도화를 구현한다. 기존 자동 실행·푸시 권한을 유지한다. 이번의 기능/플랫폼 선택은 담당 에이전트의 판단이며 사용자 조사 결과가 아니다.

## 방향과 선택

아이템 수 확대는 콘텐츠 양을 늘리지만 혼자 시작할 수 없는 문제를 해결하지 않는다. 서비스 배포 강화는 필요하지만 호스트와 실제 Supabase 자격증명 없이는 공개 운영을 검증할 수 없다. 이번에는 Node.js/WebSocket/브라우저 구조를 유지해 **즉시 시작 가능한 비랭크 AI 연습전 + 행동 기반 안내 + 팀 구출 피드백**을 구현한다. 게임을 처음 경험하는 비용을 줄이고 팀 플레이를 이해하도록 한다.

## 기능과 경계

- `join.practice: true`는 새 비공개 연습방을 만든다. 서버가 랜덤 roomId를 정하고 `team` 4대4, 사람 1명+AI 7명으로 즉시 시작한다. 선택 캐릭터/스킨/맵/itemMode는 유지한다. 요청 roomId로 다른 방을 재사용하지 않는다.
- 연습전은 Supabase 없이 체험 가능하다. 실제 사람 대전의 인증 조건은 유지한다. 연습전은 프로필/경기/랭킹에 절대 저장하지 않으며 서버 `state.practice`와 화면에 비랭크/AI임을 명시한다.
- 한 프로세스에서 연습방은 최대 8개. 초과 시 `practice_unavailable`, 소유자 연결 종료 시 봇을 포함한 방을 즉시 정리한다. 종료한 경기는 2분 후 소켓 종료로 회수한다. 사람의 추가 입장을 거부한다.
- 봇은 같은 한 칸 이동·설치·다트·피격·아이템 규칙을 사용한다. 별도 스탯 혜택 없이 파괴 블록/아이템/상대를 향해 움직이고 폭탄·파동 회피, 아군 구조를 시도한다. 숙련자 수준 AI를 주장하지 않는다.
- 서버 플레이어 통계 `bombsPlaced`, `itemsCollected`, `rescues`를 누적·전송한다. 결과 점수판은 `rescues`를 포함한다. 한 버블의 중복 구조는 집계하지 않는다.
- 첫 화면에서 연습 버튼을 로그인 버튼과 별도로 제공한다. `practice-button`, `tutorial-panel`, `tutorial-toggle`, `sound-toggle`, `motion-toggle`, `rescue-alert` ID를 제공한다. 기존 smoke selectors 유지.
- 안내는 실제 이동, 실제 설치, 실제 아이템 획득을 서버 상태에서 확인한다. 아이템전 OFF에서는 아이템 단계를 요구하지 않는다. 안내 접기/다시 보기, 연습 즉시 다시 시작, 연습/정식 대전 구분을 제공한다.
- 버블 아군의 이름과 남은 초를 표시하고 캔버스에서도 구조 표식을 제공한다. 색 외에 B/P 문자 또는 모양으로 팀을 구분한다. 결과에 구조 횟수와 구조 기여를 표시한다.
- 효과음은 원본 Web Audio 합성, 기본 꺼짐, 사용자의 켜기 클릭 후 시작. 이동/설치/파동/아이템/구조/결과 등 상태 변화에 한 번씩 재생하며 음소거가 즉시 적용된다. 소리 없어도 모든 상태를 읽을 수 있다.
- 모션 줄이기는 OS 설정을 기본값으로 따르고 수동 설정을 제공한다. 저장소가 거부돼도 플레이가 동작한다. 주요 터치 버튼 최소 44px, 390px 화면 가로 넘침 없음. 완전한 스크린리더 게임 접근성을 주장하지 않는다.

## 평가

기준 커밋 `6ce7407`. 10점 척도: 완성도25%, 재미25%, 독창성20%, 접근성20%, 타겟 적합성10%. 각 항목을 관찰 가능한 하위 기준으로 평가하고 비교 점수는 전문가 추정임을 명시한다. 원작의 현재 이용자/과금/플랫폼/통계 실측은 없으며 공식 사이트는 참고 링크로만 구분한다. 타겟은 설치 없이 짧게 즐기는 초보·캐주얼 친구 그룹, 보조 타겟은 원작 경험자. 나이/성별 취향을 단정하지 않는다.

## 성공 기준

운영 게스트 비활성 상태에서도 1개 브라우저 클릭으로 AI 7명과 연습 시작, 실사용자 대전은 인증 유지, 봇 움직임·설치 확인, 비랭크 결과가 랭킹에 들어가지 않음, 종료/나가기 정리, 조작 안내 실제 진척, 설정 유지·접근성, 기존 8인 smoke 회귀 없음. 실제 재미·잔존율 개선은 별도 5명 이상 플레이테스트로 확인할 가설이다.

## 사용자 추가 요청: 신나는 캐주얼 BGM·효과음

2026-11-02 진행 중 배경음악과 효과음도 크레이지 아케이드처럼 신나고 캐주얼하게 구현하라는 요청을 받았다. 밝은 자체 멜로디·리듬을 Web Audio로 합성한다. 8마디 멜로디/코드/베이스/퍼커션을 겹치고 대기·대전·결과 장면의 편곡과 템포를 구분한다. 물방울 설치, 물 터짐, 아이템, 구조, 승리/패배 등 효과음을 구분한다. BGM/효과음 각각 기본 OFF와 켜기 버튼·독립 음량 조절을 제공하고 탭 숨김·나가기·음소거 때 타이머와 음원을 정리한다. 외부 음원 의존성과 자동 재생이 없다. 오디오 API 미지원 또는 재생 실패 시 게임은 계속 가능해야 한다. 실제 합성은 브라우저에서 검증하고, 독자 멜로디의 미리 듣기 WAV를 테스트 산출물로 만들어 확인한다.
